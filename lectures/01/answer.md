### 実行方法

Codex CLI にログインした環境で、リポジトリのルートから実行する。
`.env` がある場合は、`.env.example` の必須項目を既存の設定に記入する。
環境変数に同名の設定がある場合は、その値を優先する。

```bash
uv sync --frozen
test -f .env || cp .env.example .env
codex login status
uv run python -m app.codex_comparison
```

### 出力ファイル

保存先は `outputs/YYYYMMDD-HHMMSS-識別子/`。フォルダ名の時刻は日本時間。
質問や回答には秘密情報・個人情報を含めない。

```text
outputs/YYYYMMDD-HHMMSS-識別子/
├── question.txt          # 質問
├── prompt.txt            # 共通の指示を含む入力全文
├── settings.json         # モデル一覧、試行回数、推論設定、CLI の版と共通引数
├── summary.json          # 全試行の成否と使用量
├── model_01/
│   ├── trial_01/
│   │   ├── settings.json # この試行のモデルと実行コマンド
│   │   ├── answer.md     # 得られた回答
│   │   └── result.json   # 成否、トークン数、経過時間、外部ツールの使用
│   ├── trial_02/
│   └── trial_03/
└── model_02/
    ├── trial_01/
    ├── trial_02/
    └── trial_03/
```

モデルを交互に実行し、実行ごとに別のフォルダへ保存する。
失敗した試行は `result.json` にエラー種別を記録する。
外部ツールを使った回答は `excluded` とし、知識のみの回答との比較から除く。
回答が得られない試行には `answer.md` が存在しない。

トークン数は Codex が返す使用量であり、CLI の内部指示なども含む。
経過時間には CLI の起動と通信の時間も含む。
各3回の比較は、この質問と設定で観測できる範囲を対象とする。
