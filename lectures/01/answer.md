## 宿題

- 取り組んだレベル：基礎
- 比較内容：同じ質問を Codex の複数モデルに3回ずつ入力し、回答の内容とばらつきを比較する。
- 質問：LoRAとは何ですか？
- モデル：gpt-6.1-sol、gpt-6-luna
- 共通設定：推論の強さ medium、各回は独立した会話。外部検索・ファイル参照・コマンド実行を使わずに回答するよう指示する。
- 結果：2モデルに同じ質問を3回ずつ入力した6試行は、すべて成功として記録されている。gpt-6.1-sol は具体例や注意点まで詳しく説明し、gpt-6-luna は要点を短くまとめる傾向がある。同じモデルでも、数式や補足説明の有無には違いがある。
- 気づき・疑問：説明の詳しさと簡潔さには違いがあり、長さや応答時間だけでは回答の良し悪しを決められない。同じ質問でも入力トークン数が変わる試行があり、利用者が指定する質問以外の入力条件にも注意が必要。

### 回答内容の比較と考察

- **共通点**：両モデルとも、LoRAを少ない追加パラメータでモデルを特定の用途に適応させる手法と説明し、メモリや保存容量を抑える点に言及している。
- **モデル間の違い**：gpt-6.1-sol は3回とも言語モデルと画像生成モデルに触れ、利点だけでなく制約や注意点も示している。gpt-6-luna は短い段落で概要を説明しており、数式やQLoRAの補足はない。
- **同じモデル内の違い**：gpt-6.1-sol は1回目にQLoRA、3回目に数式を含むなど、補足内容が変わる。gpt-6-luna も、具体例や行列の積への言及の有無が変わる。中心的な説明が似ていても、同じ回答が再現されるわけではない。
- **表現の明確さ**：gpt-6-luna の1・2回目は元の重みを固定すると明記しているが、3回目は「大きく書き換える代わりに」「その部分を主に学習」という表現で、固定することの説明が曖昧。短い説明でも、重要な条件が明確かを確認する必要がある。
- **評価の限界**：経過時間にはCLIの起動と通信が含まれ、回答の長さも異なるため、モデルの処理速度そのものの比較とはいえない。質問は1種類、各モデル3回の観測であり、モデル全体の優劣や他の質問での傾向までは判断できない。
- **入力条件についての疑問**：同じ表示上のプロンプトでも、gpt-6-luna の入力トークン数は15,626・18,365・18,369と異なる。保存データだけでは原因を特定できないため、CLIの内部入力まで完全に同条件だったとは断定できない。

### 実行方法

Codex CLI にログインした環境で、リポジトリのルートから実行する。
`.env` がある場合は、`.env.example` の必須項目を既存の設定に記入する。
環境変数に同名の設定がある場合は、その値を優先する。

```bash
uv sync --frozen
test -f .env || cp .env.example .env
codex login status
uv run python -m app.codex_comparison
```

### 出力ファイル

保存先は `outputs/YYYYMMDD-HHMMSS/`。フォルダ名の時刻は日本時間。
同じ日時の保存先が存在する場合は、既存データを保持してエラーになる。
質問や回答には秘密情報・個人情報を含めない。

```text
outputs/YYYYMMDD-HHMMSS/
├── question.txt          # 質問
├── prompt.txt            # 共通の指示を含む入力全文
├── settings.json         # モデル一覧、試行回数、推論設定、CLI の版と共通引数
├── summary.json          # 全試行の成否と使用量
├── model_01/
│   ├── trial_01/
│   │   ├── settings.json # この試行のモデルと実行コマンド
│   │   ├── answer.md     # 得られた回答
│   │   └── result.json   # 成否、トークン数、経過時間、外部ツールの使用
│   ├── trial_02/
│   └── trial_03/
└── model_02/
    ├── trial_01/
    ├── trial_02/
    └── trial_03/
```

モデルを交互に実行し、実行ごとに別のフォルダへ保存する。
失敗した試行は `result.json` にエラー種別を記録する。
外部ツールを使った回答は `excluded` とし、知識のみの回答との比較から除く。
回答が得られない試行には `answer.md` が存在しない。

トークン数は Codex が返す使用量であり、CLI の内部指示なども含む。
経過時間には CLI の起動と通信の時間も含む。
各3回の比較は、この質問と設定で観測できる範囲を対象とする。
