mcpサーバーのフレームワークとかは指定ある？

**特定のフレームワークを必須とする明記はありません。** ただし、課題は配布済みのMCPサーバーへツールを登録する前提です。

```python
from mcp.server.mcpserver import MCPServer

server = MCPServer("aie2026-glossary")
server.tool()(tools.search_glossary)
```

- **サーバー側**：MCP Python SDKの`MCPServer`
- **配布コードのクライアント側**：Pydantic AI

この回から依存パッケージが増えているのでupstreamを持ってこいって書いてるけど、これって今の時点では公開されてないってこと？



----



**第5回のコードと依存定義は、すでに公開されています。公開待ちという意味ではありません。**

課題文には、別々の2つの準備手順があります。

| 手順 | 意味 |
|---|---|
| `uv sync --frozen` | 手元の`uv.lock`に合わせて、MCP関連を含む依存パッケージを環境へ導入する |
| `git fetch upstream --tags` | 前の回が終わっていない場合に、開始タグから演習を始めるための代替手順 |

実際、upstreamの[依存定義](https://github.com/matsuolab/lecture-ai-engineering-2026/blob/main/pyproject.toml)には`pydantic-ai-slim[google,mcp]`があり、[MCPサーバーのコード](https://github.com/matsuolab/lecture-ai-engineering-2026/blob/main/app/mcp_server.py)も公開されています。手元にも両方あり、ルートの環境には`mcp 2.3.0`が入っています。

**ただし、現時点の公開リモートには`lec05-start`タグが見つかりませんでした。** タグを使う代替手順は、資料と公開状態が一致していないようです。

あなたの場合は必要な配布コードが手元にあるので、**タグの公開を待たずにlec05を進められます。**
